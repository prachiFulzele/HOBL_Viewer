P50 changes between consecutive builds

Fix one device, RAM configuration, and scenario. Metrics shown in Table (Specified) are selected by default; open the metric picker to add or remove metrics. Builds are compared in numeric build-number order, each against the preceding included build.

Counts iterations containing valid samples for each selected metric. Applies only to Build Regression.

P50 is the median of all finite samples for each selected metric in each build, across all hosts, dates, and iterations. Metrics with different units or Perftrack IDs are kept separate. Percentage change = (current P50 - previous P50) / |previous P50| × 100. Any worsening is labeled a regression; this is not a statistical-significance test. A zero previous P50 has no percentage change.
